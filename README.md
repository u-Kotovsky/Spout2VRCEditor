# Spout2VRCEditor
Spout2VRCEditor is a toolset that lets you quickly test RenderTextures in playmode through Spout2 texture sharing

## What is this for?
When you need to quickly test visuals, light data or other things without relying on streaming through a server that has latency.

## How to install
[Get on VCC](https://u-kotovsky.github.io/vpm-listing/)

## Dependencies
- [KlakSpout](https://github.com/u-Kotovsky/KlakSpout) (Included in VPM dependency)

## Supported stuff

### Supported platforms
This is most likely Windows-only since Spout2 runs natively on Windows only. But feel free to modify this to have other options for this like pipewire on Linux.

### Supported screen configurations
This is mostly for Render Textures, if you update your screens via material update, please dont

## How to set it up

### Base setup
1. In Unity Editor, go to your toolbar > Tools > Spout2VRCEditor
   - It's a configuration window with minor controls
   - From there you can choose what Spout2 texture your Render Textures will receive.
2. Enter playmode
3. See the result
